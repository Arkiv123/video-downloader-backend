THE API.

One HTTP request in, every downloadable format out. No SDK, no key to start, no rate-limit for light use — just POST a URL and read the JSON. The same engine that powers the site.

Base URL

https://video-downloader-backend-79wc.onrender.com

1 · List formats

POST/formats
Send a video URL, get back the title, thumbnail, duration and every video/audio track it carries.
# request
curl -X POST .../formats \
  -H "Content-Type: application/json" \
  -d '{"url":"https://youtube.com/watch?v=..."}'

# response
{
  "title": "...", "thumbnail": "...", "duration": 212,
  "formats": [
    {"format_id":"137","type":"video","label":"1080p","ext":"mp4","filesize":52428800},
    {"format_id":"140","type":"audio","label":"Audio","ext":"m4a","filesize":3400000}
  ]
}

2 · Download

POST/download
Pass the URL and a format_id from /formats. The server fetches, merges audio+video if needed, and streams the file back with a filename.
# request
curl -X POST .../download \
  -H "Content-Type: application/json" \
  -d '{"url":"...","format_id":"137","audio_only":false}' \
  --output video.mp4

3 · Stream

POST/stream
Same inputs as /download, but proxies the media as a live stream — handy for piping without buffering the whole file server-side.
